Step-by-Step Tutorial

01

Create a Collection with 3 Requests

▼

Open Postman and create a new Collection called User Posts Pipeline. Add these three requests:

GET https://jsonplaceholder.typicode.com/users/{{userId}} Fetch User
GET https://jsonplaceholder.typicode.com/posts?userId={{userId}} Get User Posts
GET https://jsonplaceholder.typicode.com/posts/{{postId}} Get Post Detail
💡 Tip: Use {{userId}} as a Collection variable. Set it to 1 in the Variables tab to start.
02

Build the Flow in Postman Flows

▼

Click Flows in the left sidebar → New Flow. Then connect your requests visually:

📤 Output
  1. Drag a Send Request block → select Fetch User
  2. Add a Select block → pick body.id from the response
  3. Connect to another Send Request block → select Get User Posts
  4. Add another Select block → pick body[0].id
  5. Connect to the final Send Request → Get Post Detail
  6. Add an Output block to display the final result
03

Run the Flow and Inspect Results

▼

Click ▶ Run in the top-right of the Flow editor. Watch each block execute in real time.
